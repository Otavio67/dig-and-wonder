## Estado de produção

Fundos são imagens únicas, opacas; ainda não têm camadas independentes, bordas testadas para repetição ou integração parallax. A proporção/enquadramento deverá ser ajustada na composição mobile.

O HUD é uma imagem conceitual com texto rasterizado. Ao implementar, separar molduras, ícones, botões e demais componentes, renderizar texto/números por TMP e usar dados reais. Os números, missão, recompensa, AUTO, força e slots do conceito são ilustrativos; não indicam sistemas novos já implementados. A execução real continua seguindo a economia e o comportamento existentes até uma tarefa de implementação autorizada.

## Revisão visual

Preservada a identidade da Pioneira usando sua folha de sprites como referência. Mantidos metal escuro, planos de fundo mais suaves, luz quente/ciano, chapas chanfradas, ouro com ícone de moeda e baixo uso de engrenagens. Na segunda versão do conceito, espadas viraram brocas de ataque, vida usa coração blindado, botões receberam verde oficina e seleção ganhou marcador ciano. Tipografia gerada é uma aproximação visual; Titan One/Nunito reais serão aplicadas no Unity. Contraste e toque não foram medidos.
